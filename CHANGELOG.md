# Changelog

## 0.1.0-preview.1

- Source-only experimental maintenance snapshot based on fif_gui.
- Browser login waits for oral-site session state and permits manual verification.
- Oral-site profile requests carry authentication headers and validate userId.
- Task list responses are validated; an empty GUI task list supports read-only filter diagnostics.
- Includes local checkpoints, voice utilities and Windows output-device selection.
- Adds public configuration defaults, offline CI/tests and publishing documentation.

Not yet verified: a complete live teacher-task recording, grading and submission cycle.
Machine-specific driver rollback scripts and temporary download scripts are intentionally excluded.
